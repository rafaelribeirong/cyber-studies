# 07 — Conformidade

Esta seção analisará como funcionalidades do Wazuh podem implementar controles técnicos, apoiar processos e produzir evidências para sistemas de gestão.

Escopo inicial:

- ISO/IEC 27001;
- ISO/IEC 27701;
- matriz Wazuh x controles;
- exemplos de evidências técnicas;
- limitações da ferramenta.

## Regra de classificação

Os mapeamentos devem utilizar:

- **IMPLEMENTA**;
- **APOIA**;
- **EVIDÊNCIA**;
- **FORA DO ESCOPO**.

O Wazuh não deve ser apresentado como ferramenta que, isoladamente, garante conformidade ou certificação.
