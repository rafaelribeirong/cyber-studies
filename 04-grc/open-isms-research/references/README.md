# Catálogo de referências

O catálogo reunirá somente fontes efetivamente consultadas. Cada registro indicará:

- tipo de fonte;
- entidade ou autor;
- título;
- edição ou versão;
- publicação e vigência;
- URL, DOI ou referência bibliográfica;
- data de acesso;
- páginas do projeto que utilizaram a fonte.

Normas protegidas por direitos autorais serão citadas e interpretadas, não reproduzidas integralmente.
