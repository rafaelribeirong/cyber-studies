# Bug Bounty

Trilha separada para estudos de segurança de aplicações e pesquisa de vulnerabilidades em ambientes autorizados.

Foco inicial:

- Autorização e controle de acesso
- IDOR / BOLA
- Isolamento multi-tenant
- Mass Assignment / BOPLA
- Lógica de negócio
- Autenticação, sessão e JWT
- Documentação de laboratórios e metodologia de testes

Todo conteúdo desta área deve ser utilizado somente em ambientes próprios, laboratórios ou programas com autorização explícita.
